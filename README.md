## "RM xx/月"到底怎么算：三种口径，三种总支出

这是比价时最容易翻车的地方。同样写着"每月多少钱"，背后可能是三种完全不同的算法。

第一种是长周期折算价。VPS Malaysia 的 Windows VPS 页面标 Basic RM22.9/月、Save 54%，但链接指向的是三年付周期。也就是说 RM22.9 是你一次性付三年才拿到的折合月价，一次性支出是 22.9 × 36 = RM824.4。而且页面底部写明"Exclusive of 8% Service Tax"，加税后实际支出约 RM890，折合每月约 RM24.7。

第二种是年付折扣价。GB Network 的 Windows KVM VPS 标 Mini RM62.91/月，注明"Save 10% for 12-months plan"，一年一次付清是 RM754.92。这个数字和"每月付一次"的体感差着一截，续费时按什么价，页面没写。

第三种是标准月价加续费承诺。Vebloom 标 $19.99/月起，明确写"你注册时的价格就是你续费时的价格"，第一年 $239.88，第二年还是 $239.88。

Evoxt 的价目属于第三种口径的报价形式，标的是美元月付。$5.99/月的 VM-1，按月付满一年是 $71.88。官方价格页没有披露续费政策，也没有列出年付折扣，这两点在下单前要在结账页自己确认一遍。

三种口径放一起，能看出方法：看到"RM xx/月"先问三句——这个月价对应哪个付款周期、含不含税、续费按什么价。三个答案里有一个不清楚，这个数字就不能拿去和别家比。币种还不同，马币和美元之间还要过一道汇率，硬排名没有意义。

## 客户在马来西亚：PDPA 与数据留在境内

马来西亚《2010 年个人数据保护法》（PDPA 2010）管的是商业交易中的个人数据处理，由个人数据保护局监管，原则覆盖告知与选择、披露、安全、保留、数据完整性与访问，历史上对个人数据出境设过条件。金融行业另有一层：Bank Negara Malaysia 对金融机构的外包和数据位置有自己的要求。

这条对做本地客户生意的读者是决策级的。你给一家马来西亚银行、医院、政府关联公司或大雇主做系统，对方的信息安全问卷里大概率有一栏问"数据存放在哪里"。源站在吉隆坡，这一栏填起来最省事；源站在新加坡或美国，就要走一遍跨境评估。

合规不止机房位置。拿到 root 权限之后，加密、访问控制、日志、备份保留都是你自己负责的部分，PDPA 下的责任不会因为换了机房就转移给服务商。Evoxt 提供外部防火墙规则、浮动 IP、VNC 和每周异地备份，这些是工具，怎么配是你的事。
